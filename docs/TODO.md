Phase 1 — MVP (룸 기반 캐릭터 채팅이 되는 상태)

프롬프트 엔진 (시스템 프롬프트 + 캐릭터 설명 + 대화 기록 조립)
AI 프로바이더 1개 연동 (OpenAI or Claude)
채팅 UI (메시지 입력 → 스트리밍 응답 표시)
룸 생성/선택
룸에 캐릭터 참조 추가
채팅에 페르소나 참조 추가
채팅별 selected/default 캐릭터·페르소나 지정

토큰 관리 (컨텍스트 리밋 내에서 메시지 자르기)
페르소나 시스템
멀티 캐릭터/멀티 페르소나 프롬프트 블록 옵션
Greeting sync (캐릭터별 greeting swipe)
